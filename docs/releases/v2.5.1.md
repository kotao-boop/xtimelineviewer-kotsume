# XTimelineViewer Kotsume Edition v2.5.1

## 自動翻訳ボタンをすっきり整理

v2.5.1は、v2.5.0で追加した自動翻訳機能の操作場所を見直した更新です。

- 自動翻訳ボタンを、列ヘッダーの三点メニュー内へ移動
- 列ヘッダーの操作を「自動翻訳」「集中表示」「一時非表示」「設定」に整理
- 狭い列でも投稿本文を隠さず、内容を読みやすい状態に改善
- 設定画面から、自動翻訳ボタンを「三点メニュー内」「ヘッダーに表示」「表示しない」から選択可能
- 日本語・英語の表示とキーボード操作に対応

## これまでの改善も収録

- 上部のワークスペースタブ
- 統一された列追加画面と高度な検索条件ビルダー
- 各列の新着件数、自動整列、集中表示、一時非表示、列サイズ変更
- 設定とワークスペースのバックアップ・復元
- 「ボスが来た」モードとKotsume Edition専用アイコン
- x64版とARM64版

## プライバシー

翻訳は初期状態でOFFです。利用者が画面上の説明に同意した場合だけ、表示中の投稿本文をGoogleの
翻訳用エンドポイントへ送信します。同意は列の詳細設定から取り消せます。XはMicrosoft Edge
WebView2で表示し、本アプリがEdgeのCookieを読み取ったりコピーしたりすることはありません。

## 配布上の注意

GitHub版のEXE／ZIPはコード署名されていません。Windowsが「不明な発行元」またはSmartScreenの
警告を表示する場合があります。リリースに添付されたSHA-256とGitHub Artifact Attestationで、
公式ワークフローが生成したファイルであることを確認できます。Microsoft Store版はMicrosoftが
署名する別の配布経路です。
