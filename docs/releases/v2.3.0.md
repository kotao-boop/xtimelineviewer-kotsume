## v2.2.0からの主な変更

### 初めて使う人にも分かりやすい画面

- 3段階の初期設定に進行表示と戻る操作を追加しました。
- ［あとで設定］を選んでもアプリを終了せず、メイン画面から設定を続けられるようにしました。
- タイムラインが空のときに、ホーム、通知、ブックマーク、リストをすぐ追加できる案内を表示します。
- 上部ツールバーから、プロフィール、タイムライン追加、投稿、検索、レイアウトへ直接移動できます。

### タイムラインを整理する新機能

- タイムラインの名前変更、表示・非表示、並べ替え、複製、削除をまとめて行える管理画面を追加しました。
- 用途ごとのタイムライン構成とレイアウトを保存して切り替えるワークスペース機能を追加しました。
- ホーム、通知、ブックマーク、検索、リストなどを、URLではなく分かりやすい名前で表示します。
- 読み込み中、接続エラー、ログインが必要な状態を区別し、再試行や外部ブラウザーを選べるようにしました。

### 検索と操作の効率化

- 検索結果を右側のパネルに表示し、元のタイムラインを残したまま確認できるようにしました。
- `Ctrl+K`で操作を検索できるコマンドパレットを追加しました。
- `F1`でキーボードショートカット一覧を開けるようにしました。
- タイムライン数に合うレイアウトを提案しますが、利用者の許可なく自動変更はしません。

### 設定、プロフィール、表記の改善

- 設定検索を追加し、目的のカテゴリーへ移動しやすくしました。
- 同じプロフィール情報を保ったままXへ再ログインできるようにしました。
- 日本語と英語の翻訳項目が一致しているかを自動テストするようにしました。
- Kotsume Editionの現在の保守者と、元のXTimelineViewer作者を区別して表示します。

## ファイルを確認する方法

まず、目的のパッケージと`SHA256SUMS.txt`を同じフォルダーへ保存します。PowerShellで次を実行すると、
実際のSHA-256を表示できます。

```powershell
Get-FileHash .\XTimelineViewer-Kotsume-v2.3.0-Setup.exe -Algorithm SHA256
```

表示された64文字の値が`SHA256SUMS.txt`の同じファイル名の値と完全に一致することを確認してください。
GitHub CLIを使える場合は、来歴証明も確認できます。

```powershell
gh attestation verify .\XTimelineViewer-Kotsume-v2.3.0-Setup.exe --repo kotao-boop/xtimelineviewer-kotsume
```

SHA-256は「公開されたファイルと同じか」、Artifact Attestationは「このリポジトリのGitHub Actionsが
作ったファイルか」を確認する助けです。どちらも、発行者をWindowsへ証明するAuthenticodeコード署名や、
ソフトウェアの安全性の保証そのものではありません。

## プライバシーと通信

- Xの画面はMicrosoft Edge WebView2で表示します。
- 任意の翻訳機能を有効にした場合だけ、画面に見えている投稿本文をGoogleの翻訳用エンドポイントへ送ります。
- 更新確認では、このリポジトリのGitHub Releases APIへ接続します。
- 詳細は[プライバシーポリシー](https://github.com/kotao-boop/xtimelineviewer-kotsume/blob/main/PRIVACY.md)を確認してください。

## 既知の制限

- 未署名のため、Windowsの警告が表示されることがあります。
- Xの画面構造が変更されると、一部機能が一時的に動かなくなる可能性があります。
- 自動翻訳にはGoogle側への通信が必要です。翻訳を使わない場合はOFFのまま利用できます。
- Microsoft Store版は2026年8月26日に正式なPartner Center Identityで認定申請済みで、現在審査中です。認定結果が出るまでは公開済みとは扱いません。
