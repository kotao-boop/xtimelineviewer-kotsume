# XTimelineViewer Kotsume Edition v2.5.2

## 自動翻訳拡張機能の重複登録を整理

v2.5.2は、v2.5.1で変更した自動翻訳ボタンの配置が一部の環境で反映されない問題を修正する保守更新です。

- WebView2のプロファイルごとに拡張機能を初期化
- 現在のアプリに同梱された翻訳拡張機能を優先して登録
- 過去のインストール場所から残った同名の古い翻訳拡張機能を自動削除
- 複数ペイン・複数プロファイルを使っても設定画面に同じ拡張機能を重複表示しないよう改善
- 翻訳の同意状態は、同じ拡張IDを更新できる場合はできるだけ維持

これにより、Xのページ上に残っていた旧版の固定「自動翻訳: ON」ボタンが、次回起動後に再び表示される問題を解消します。

## 以前の改善も収録

- 列ヘッダーの三点メニューへの自動翻訳操作の整理
- 自動整列、一時非表示、集中表示、列サイズ変更

- x64版とARM64版

## 配布上の注意

GitHub版のEXE／ZIPはコード署名されていません。Windowsが「不明な発行元」またはSmartScreenの警告を表示する場合があります。公式GitHub Releaseから取得し、添付されたSHA-256チェックサムとGitHub Artifact Attestationでファイルを確認してください。Microsoft Store版はMicrosoftが署名する別の配布経路です。
