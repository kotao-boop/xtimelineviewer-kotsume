# XTimelineViewer Kotsume Edition v2.7.1

v2.7.1は、データ保護と信頼性を高めるためのGitHub版リリースです。

## 主な変更

- 設定・プロフィール・タイムライン・ワークスペースを安全に保存します。
- 保存前に既存データを検査し、破損やアクセスエラー時の上書きを防ぎます。
- 保存失敗時は一時ファイルを残さず、前回のバックアップを保持します。
- WebView2の終了時に非同期処理とイベントを安全に停止します。
- Google／Apple認証への誤誘導を避け、Xのログイン方法を明確に案内します。
- 高DPI環境で設定画面やプロフィール画面が崩れにくいよう調整しました。

## 注意

GitHub版のEXE・ZIPはコード署名されていません。初回起動時にWindowsの警告が表示される場合があります。公開物のSHA-256とArtifact Attestationを確認してから実行してください。

Microsoft Store版はMicrosoftが署名して配布します。
