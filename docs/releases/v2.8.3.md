# XTimelineViewer Kotsume Edition v2.8.3

Google方式の翻訳を利用者が止められるようにし、GitHub版とMicrosoft Store版で拡張機能を同じ仕組みで管理できるようにしました。

## 主な変更

- 翻訳設定からGoogle方式を無効化・再有効化できるようにしました。
- Google方式を無効にしている間は、同梱の翻訳拡張機能からGoogleへ翻訳通信を送信しません。
- Google方式を無効化した状態では、自動翻訳を停止し、設定画面から状態を確認できます。
- WebView2拡張機能の読み込みをGitHub版とMicrosoft Store版で統一しました。
- Microsoft Store版でも利用者が選んだローカル拡張機能を追加できるようにしました。
- 同梱拡張機能と利用者が追加した拡張機能を別の場所で管理し、更新時に利用者のファイルを削除しないようにしました。
- 拡張機能のファイルが使用中でも、起動時の同期処理が失敗しにくいようにしました。

## 翻訳機能について

翻訳は初期状態で無効です。利用者が同意して有効にした場合だけ、投稿本文をGoogleの翻訳用エンドポイントへ送信します。Google方式を無効にすると、同梱の翻訳拡張機能は通信を行いません。外部の拡張機能を利用者が追加した場合、その拡張機能が行う通信やサービスの制限は本アプリの設定から制御できません。

無料の公開エンドポイントは、利用制限や仕様変更によって利用できない場合があります。翻訳できない場合は、翻訳設定で状態を確認し、必要に応じてGoogle方式を再有効化してから手動で再試行してください。

## 配布上の注意

GitHub版のEXE・ZIPはコード署名されていません。初回起動時にWindowsの警告が表示される場合があります。公式GitHub Releaseから取得し、添付された`SHA256SUMS.txt`とGitHub Artifact Attestationでファイルを確認してください。

Microsoft Store版は、同じソースから作成したStore用パッケージをMicrosoftの認定後にMicrosoftの署名で配布します。Storeの審査・公開状況はMicrosoft Store側の表示を優先してください。
