# XTimelineViewer Kotsume Edition v2.4.0

## 次回Store提出に向けた改善版

v2.4.0は、Microsoft Storeの次回提出前に、認証、バックアップ、ブランド資産、日常操作をまとめて整えるための開発版です。

- Google／Appleログイン操作を通常のタイムライン画面でも検知し、外部Edgeへ意図せず飛ばさず、X用パスワードによる安全なログイン方法を案内
- Microsoft EdgeのCookieを読み取ったり、コピーしたりしない安全な認証フロー
- 設定とタイムライン構成を、ログイン情報を含めずにバックアップ・復元
- Kotsume Projectオリジナルのカワウソアイコンを、アプリ本体、ショートカット、インストーラー、タイル、スプラッシュ画面へ統一
- タイムライン下端のドラッグによる縦方向のサイズ変更と、その高さの保存
- 任意のローカル画像でタイムラインを一時的に隠す「ボスが来たモード」
- ボスモードボタンの表示・非表示を設定から選択
- 2.4.0からの改善をStore版にも反映するため、GitHub版とStore版の提出物を同じソースから作成

## 配布上の注意

GitHub版のEXE／ZIPはコード署名されていません。Windowsが「不明な発行元」またはSmartScreenの警告を表示する場合があります。Microsoft Store版はMicrosoftが署名する別の配布経路です。
