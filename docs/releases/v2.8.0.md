# XTimelineViewer Kotsume Edition v2.8.0

v2.8.0 は、タイムラインの配置、ワークスペースの切り替え、翻訳の安定性を改善する GitHub 版リリースです。

## 主な変更

- **画面に合わせた配置**：レスポンシブ配置では、画面の縦横比とタイムラインの本数から行・列を決めます。最後の行に余った場所は最後のタイムラインを広げて使います。
- **大きさをそろえる操作**：ツールバーの整列ボタンは、選択中の配置を保ちながら幅や高さを均等に戻します。配置の種類はメニューから選べます。
- **境界線の操作**：ドラッグ時に隣接する列・行だけを調整し、それ以外の大きさを保ちます。境界線は Tab キーで選び、矢印キーでも操作できます。
- **一時表示の復帰**：集中表示、一時非表示、画像・動画の拡大を分けて管理し、元の配置へ戻れるようにしました。
- **ワークスペース**：使用中の構成を自動保存してから切り替えます。同じ名前への上書きは確認ボタンを表示します。切り替え途中の部分的な構成を保存しないようにしました。
- **狭い画面とテーマ**：検索欄を折り返し、小さい画面では検索結果を広く表示します。テーマ変更時の文字色・背景色の残りや、表示倍率による初期サイズのずれを改善しました。
- **翻訳**：日本語・英語への翻訳に対応し、一時的な通信失敗を再試行します。スクロールで再利用される投稿欄に、古い本文の翻訳が表示されないようにしました。翻訳キャッシュは最大128件です。
- **長時間の利用**：動画情報の読み取りを最大4 MiB、同時処理を2件、キャッシュを512件に制限しました。ログも1件の長さとファイルの大きさを制限します。
- **保存データの保護**：起動時の読み込み失敗を表示し、自動保存を停止します。起動時に未参照のプロフィール用フォルダーを自動削除する処理も停止しました。

## 配布ファイル

通常の Windows PC には `XTimelineViewer-Kotsume-v2.8.0-Setup.exe` を使用してください。
インストールせずに使う場合は、CPUに合わせて x64 または ARM64 の Portable ZIP を選び、展開して `XTimelineViewer.exe` を起動します。

## 署名と確認

GitHub版のEXE・ZIPはコード署名されていません。初回起動時にWindowsの警告が表示される場合があります。公開物の `SHA256SUMS.txt` と GitHub Artifact Attestation で配布ファイルを確認できます。これらはコード署名の代わりではありません。

翻訳は初期状態でOFFです。同意した場合だけ投稿本文をGoogleの翻訳用エンドポイントへ送信します。翻訳設定から同意を取り消せます。外部サービスやXの画面変更によって機能の動作が変わる場合があります。

Microsoft Store版は別の配布経路です。このGitHubリリースによってStore版が自動的にv2.8.0へ更新されることはありません。
