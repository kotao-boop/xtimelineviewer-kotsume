# XTimelineViewer Kotsume Edition v2.8.5

拡張機能を利用者が個別に管理できるようにした機能改善リリースです。

## 主な変更

- 「設定 → 拡張機能」の各カードにオン／オフスイッチを追加しました。
- アプリに同梱された拡張機能と、利用者が追加したChromium拡張機能を個別に無効化できます。
- スイッチの状態を保存し、次回起動後も同じ設定で利用できます。
- 設定を変更すると、ログイン状態を保ったままタイムラインを自動的に読み直します。
- 拡張機能の読み込みに失敗した場合も、設定画面で状態と診断情報を確認し、オン／オフの切り替えで再読み込みできます。

## 使い方

1. アプリメニューから「設定」を開きます。
2. 「拡張機能」を選びます。
3. 使わない拡張機能のスイッチをオフにします。

翻訳拡張機能をオフにした場合、翻訳機能は使えなくなります。再び使うときは同じスイッチをオンにしてください。Google方式の翻訳を含む翻訳の同意や通信設定は、これまでどおり翻訳設定から変更できます。

## 配布上の注意

GitHub版のEXE・ZIPはコード署名されていません。初回起動時にWindowsの警告が表示される場合があります。公式GitHub Releaseから取得し、添付された`SHA256SUMS.txt`とGitHub Artifact Attestationでファイルを確認してください。

Microsoft Store版は、同じソースから作成したStore用パッケージをMicrosoftの認定後にMicrosoftの署名で配布します。Storeの審査・公開状況はMicrosoft Store側の表示を優先してください。
