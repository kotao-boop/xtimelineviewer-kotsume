# XTimelineViewer Kotsume Edition v2.8.1

v2.8.1は、起動時に翻訳拡張機能の読み込みが失敗することがある問題を修正したメンテナンスリリースです。

## 主な変更

- 複数のタイムラインを同時に開いたとき、翻訳拡張機能のファイルを別の初期化処理が削除しないようにしました。
- 拡張機能の更新では一時フォルダーを準備してから切り替えるため、WebView2が使用中の`content.css`を直接削除しないようにしました。
- 同じプロファイルで始まる拡張機能の読み込みを共有し、起動直後の競合を避けるようにしました。
- 拡張機能の更新中に既存ファイルを使用中でも、次回起動時に再試行できるようにしました。

## 修正された症状

起動時に「拡張機能の読み込みに失敗しました」と表示され、ログに次のような内容が残ることがある問題を修正しました。

`System.IO.IOException: The process cannot access the file 'content.css' because it is being used by another process.`

## 配布上の注意

GitHub版のEXE・ZIPはコード署名されていません。初回起動時にWindowsの警告が表示される場合があります。公開物の`SHA256SUMS.txt`とGitHub Artifact Attestationを確認してから実行してください。

Microsoft Store版はMicrosoftが署名する別の配布経路です。Store版の更新は、GitHubリリースとは別にPartner Centerへ提出します。
