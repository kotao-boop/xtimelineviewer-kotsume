# XTimelineViewer Kotsume Edition v2.8.7

セキュリティ更新を反映したメンテナンスリリースです。

## 主な変更

- .NET SDKを8.0.426へ更新し、自己完結型配布物へ.NET 8.0.32を含めるようにしました。
- Windows App SDKをサポート中の2.5.1へ更新しました。
- WebView2 SDKを1.0.4314.35へ更新しました。
- Windows 10.0.26100系のWindows SDK BuildToolsを10.0.26100.9169へ更新しました。
- x64とARM64のGitHub版・Microsoft Store版で、同じ依存関係を使ってビルドできるようにしました。
- 既存の翻訳機能の同意、通信制限、Google方式のオン／オフ設定は変更していません。

## セキュリティと配布について

GitHub版のEXE・ZIPはコード署名されていません。公式GitHub Releaseから取得し、添付された`SHA256SUMS.txt`とGitHub Artifact Attestationでファイルを確認してください。

Microsoft Store版は別の提出・更新経路で管理され、Microsoft Store側で署名されます。GitHub版とStore版は同じソースと依存関係を使い、署名と更新方法だけが異なります。

翻訳機能は初期状態でオフです。翻訳を有効にした場合の通信は、設定画面で表示される同意内容とプライバシーポリシーに従います。Google側の公開エンドポイントの制限や仕様変更によって、翻訳が一時的に利用できない場合があります。
