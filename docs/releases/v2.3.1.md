# XTimelineViewer Kotsume Edition v2.3.1

> [!WARNING]
> GitHubで配布するEXE・ZIPはコード署名されていません。Windowsで「不明な発行元」または
> Microsoft Defender SmartScreenの警告が表示される場合があります。Microsoft Store版は、
> Storeの認定後にMicrosoftが署名して配布します。

## v2.3.0からの変更

- Kotsume Edition専用のオリジナルなコツメカワウソアイコンへ刷新しました。
- 16～50ピクセル向けの簡略版を用意し、小さい表示でも識別しやすくしました。
- Storeアイコンの四隅を濃紺で埋め、白い台紙や隙間が見えないようにしました。
- 本家由来の旧アイコン資産と古い制作記録を削除しました。
- アプリ内の旧アイコン制作者向け謝辞とCrowdWorksリンクを削除しました。
- 新アイコンの由来、原画、書き出しファイル、管理方法を文書化しました。
- アカウント名を手作業で削除した実画面スクリーンショットをStore更新用に追加しました。

アプリ機能、ワークスペース、プロフィール、設定、WebView2データの保存形式に変更はありません。

## 配布経路と署名

- Microsoft Store版：Microsoft Storeが署名し、Store経由で更新します。
- GitHub版：未署名です。SHA-256とGitHub Artifact Attestationで配布ファイルを確認できますが、
  これらはコード署名や安全性の保証そのものではありません。

## プライバシーと通信

- Xの画面はMicrosoft Edge WebView2で表示します。
- 翻訳は初期状態でOFFです。
- 利用者が説明を確認して同意した場合だけ、表示中の投稿本文をGoogleの翻訳用エンドポイントへ送ります。
- Store版の更新はMicrosoft Store、未パッケージ版の更新確認はGitHub Releases APIを使用します。
- 詳細は[プライバシーポリシー](../../PRIVACY.md)を確認してください。

## 検証予定

- x64 / ARM64ビルド
- 210件の単体テスト
- UIスモークテスト
- CodeQL
- 依存関係レビュー
- Store Identityと2.3.1.0の版数一致
- MSIXUpload内のアイコン、ライセンス、第三者通知
- SHA-256とGitHub Artifact Attestation（GitHub版）

Store更新の認定結果は、Partner Centerに結果が表示されるまで合格扱いにしません。
