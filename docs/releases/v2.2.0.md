## どのファイルを選べばよいか

| ファイル | 向いている人 |
|---|---|
| `XTimelineViewer-Kotsume-v2.2.0-Setup.exe` | 一般的なIntel/AMD搭載Windows PCへインストールしたい人 |
| `XTimelineViewer-Kotsume-v2.2.0-win-x64-Portable.zip` | 一般的なIntel/AMD搭載PCで、インストールせず使いたい人 |
| `XTimelineViewer-Kotsume-v2.2.0-win-arm64-Portable.zip` | ARM64版Windows PCを使っている人 |

`UNSIGNED-RELEASE.txt`は未署名についての注意書き、`SHA256SUMS.txt`はダウンロードしたファイルが
公開時のものと同じかを確認するための一覧です。

## v2.1.0からの主な変更

- アプリとWebView2の間の通信を、信頼できるXの画面と安全なURLに限定しました。
- 翻訳は初期状態でOFFのままです。初回利用時に、投稿本文をGoogleの翻訳用エンドポイントへ送ることを
  説明し、利用者が同意してから有効にします。同意は設定画面から取り消せます。
- 大きすぎる画像・動画・ストリームを扱う際の上限とキャンセル処理を追加し、メモリ不足や停止の危険を
  減らしました。
- 依存関係をロックし、第三者ライセンス文書、x64/ARM64ビルド、UIスモークテスト、CodeQL、
  dependency reviewを公開前に確認する仕組みを整えました。
- アプリ、ランチャー、インストーラー、Store用マニフェストの版数を2.2.0へ統一しました。
- GitHub Releaseの最終ファイルにSHA-256とGitHub Artifact Attestationを付けるようにしました。

## ファイルを確認する方法

まず、目的のパッケージと`SHA256SUMS.txt`を同じフォルダーへ保存します。PowerShellで次を実行すると、
実際のSHA-256を表示できます。

```powershell
Get-FileHash .\XTimelineViewer-Kotsume-v2.2.0-Setup.exe -Algorithm SHA256
```

表示された64文字の値が`SHA256SUMS.txt`の同じファイル名の値と完全に一致することを確認してください。
GitHub CLIを使える場合は、来歴証明も確認できます。

```powershell
gh attestation verify .\XTimelineViewer-Kotsume-v2.2.0-Setup.exe --repo kotao-boop/xtimelineviewer-kotsume
```

SHA-256は「公開されたファイルと同じか」、Artifact Attestationは「このリポジトリのGitHub Actionsが
作ったファイルか」を確認する助けです。どちらも、発行者をWindowsへ証明するAuthenticodeコード署名や、
ソフトウェアの安全性の保証そのものではありません。

## プライバシーと通信

- Xの画面はMicrosoft Edge WebView2で表示します。
- 任意の翻訳機能を有効にした場合だけ、画面に見えている投稿本文をGoogleの翻訳用エンドポイントへ送ります。
- 更新確認では、このリポジトリのGitHub Releases APIへ接続します。
- 詳細は[プライバシーポリシー](https://github.com/kotao-boop/xtimelineviewer-kotsume/blob/main/PRIVACY.md)を確認してください。

## 既知の制限

- 未署名のため、Windowsの警告が表示されることがあります。
- Xの画面構造が変更されると、一部機能が一時的に動かなくなる可能性があります。
- 自動翻訳にはGoogle側への通信が必要です。翻訳を使わない場合はOFFのまま利用できます。
- v2.2.0公開時点ではMicrosoft Store版はまだ公開しておらず、Store用の開発Identityを提出しない安全装置を維持していました。現在の状況は、[最新のStore提出状況](../MICROSOFT_STORE_PUBLISHING.md)を確認してください。
