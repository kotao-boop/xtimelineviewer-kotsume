# XTimelineViewer Kotsume Edition v2.7.0

## 好きな見た目で、タイムラインをもっと広く

v2.7.0は、テーマの選択肢を増やし、自動整列とサイズ変更を実際の使い方に合わせて磨き直した更新です。

## 新しいカラーテーマ

- サイバーパンク、ネオン・コントラスト、ミッドナイト・オーシャン、フォレスト、サクラを追加
- 明るい画面、落ち着いた暗い画面、輪郭がはっきりした高コントラスト表示を用途に合わせて選択可能
- テーマを切り替えたとき、以前のテーマの色が一部に残る問題を修正

## 自動整列とサイズ変更

- 自動整列を押しても、クラシックやグリッドなど、現在選んでいる配置方式を維持
- クラシック配置では、表示中の列が利用可能な横幅を隙間なく使うよう改善
- 自動整列の後も、列の境界線をマウスでドラッグしてサイズ変更可能
- サイズ変更用の境界線を列の上から下まで操作できるようにし、つかみやすさを改善
- 表示しきれない列が突然消えたように見えないよう、配置計算を整理

## 画面を広く使うための改善

- 上部バー、ワークスペース欄、列ヘッダーを省スペース化
- ワークスペースが未登録のときは空の専用行を表示せず、保存・管理ボタンを上部へ移動
- 列のURLは常時表示せず、列名にマウスを合わせると確認できるよう変更
- 「検索」「＋タイムライン」「投稿」など、上部バーの文字が欠ける問題を修正

## 配布上の注意

GitHub版のEXE／ZIPはコード署名されていません。Windowsが「不明な発行元」またはSmartScreenの警告を表示する場合があります。公式GitHub Releaseから取得し、添付されたSHA-256チェックサムとGitHub Artifact Attestationでファイルを確認してください。Microsoft Store版はMicrosoftが署名する別の配布経路です。
