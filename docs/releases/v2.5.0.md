# XTimelineViewer Kotsume Edition v2.5.0

## タイムラインを見渡し、必要な列へすぐ集中できる更新

v2.5.0では、複数のタイムラインを日常的に使うときの操作をまとめて改善しました。

- 上部のワークスペースタブから、用途ごとのタイムライン構成をすばやく切り替え
- ホーム、通知、検索、リストなどを同じ列追加画面から選択
- 言葉、送信元、除外語、期間などを組み合わせられる高度な検索条件ビルダー
- 各列の新着件数と、再読み込み、集中表示、一時非表示などのクイック操作
- 列の幅と高さをドラッグで変更し、残った列を自動整列
- 自動翻訳ボタンをXのページ上から列ヘッダーへ移し、投稿やXの操作を覆わない配置へ改善
- 設定ウィンドウを広げ、小さい画面では自動的に収まる大きさへ調整

## これまでの改善も収録

- 設定とワークスペースを、ログイン情報を含めずにバックアップ・復元
- Google／Appleの外部認証がアプリ内で完了できない場合の安全なXログイン案内
- 任意の画像へ切り替えてタイムラインを一時的に隠す「ボスが来たモード」
- Kotsume Edition専用のオリジナルカワウソアイコン
- x64版とARM64版

## プライバシー

翻訳は初期状態でOFFです。利用者が画面上の説明に同意した場合だけ、表示中の投稿本文をGoogleの
翻訳用エンドポイントへ送信します。同意は列の詳細設定から取り消せます。XはMicrosoft Edge
WebView2で表示し、本アプリがEdgeのCookieを読み取ったりコピーしたりすることはありません。

## 配布上の注意

GitHub版のEXE／ZIPはコード署名されていません。Windowsが「不明な発行元」またはSmartScreenの
警告を表示する場合があります。リリースに添付されたSHA-256とGitHub Artifact Attestationで、
公式ワークフローが生成したファイルであることを確認できます。Microsoft Store版はMicrosoftが
署名する別の配布経路です。
