# XTimelineViewer Kotsume Edition v2.3.4

## 重要なログイン案内の改善

v2.3.3でGoogleログインを試すと、認証画面が外部のMicrosoft Edgeへ移り、Googleでログインした後に白い画面で止まる問題が残っていました。

Googleはアカウント保護のため、アプリに埋め込まれたWebViewでGoogle OAuthを行うことを認めていません。一方、外部Edgeで作られたXのログイン状態（Cookie）をXTimelineViewerのWebView2へ安全に渡すこともできません。このため、外部ブラウザー方式を続けても、XTimelineViewer内のログインは完了しません。

v2.3.4では、次のように変更しました。

- Google／Appleログインを選んだとき、意図せず外部Edgeへ移動する経路を遮断
- ポップアップ、同一画面の移動、外部URI起動、Xログイン画面のボタンクリックをそれぞれ検出
- なぜ完了できないのかを、アプリ内で日本語・英語により説明
- Xのメールアドレス、ユーザー名、または電話番号と「X用パスワード」でログインする方法を案内
- X用パスワードが分からない場合に、利用者が明示的に選んだときだけXのパスワード再設定ページを外部ブラウザーで開く
- 認証URLをログへ記録する場合も、メールアドレス、認証コード、`state`などを含むクエリとフラグメントを保存しない

GoogleまたはAppleを使ってXアカウントを作成した場合でも、X用パスワードを設定すれば、XTimelineViewer内ではメールアドレス・ユーザー名・電話番号とX用パスワードでログインできます。パスワードそのものをXTimelineViewerが保存・読み取ることはありません。
