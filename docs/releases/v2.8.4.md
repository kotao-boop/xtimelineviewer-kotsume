# XTimelineViewer Kotsume Edition v2.8.4

翻訳機能の動作状態と、拡張機能の読み込み失敗を確認しやすくするメンテナンスリリースです。

## 主な変更

- 翻訳のオン／オフと、翻訳サービスの状態を分けて表示するようにしました。
- 通信制限、通信エラー、翻訳拡張機能の未読み込み、Google方式の無効化をタイムライン上で確認できるようにしました。
- 翻訳設定の名前と説明を見直し、同じアカウントのタイムラインへ設定が共有されることを明記しました。
- 拡張機能の読み込み失敗で起動を止めず、設定画面で失敗した拡張機能、診断情報、復旧方法を確認できるようにしました。
- 診断情報をクリップボードへコピーできるようにしました。

## 翻訳機能について

翻訳は初期状態で無効です。利用者が同意して有効にした場合だけ、投稿本文をGoogleの翻訳用エンドポイントへ送信します。Google方式を無効にすると、同梱の翻訳拡張機能は通信を行いません。無料の公開エンドポイントは、利用制限や仕様変更によって利用できない場合があります。

## 配布上の注意

GitHub版のEXE・ZIPはコード署名されていません。初回起動時にWindowsの警告が表示される場合があります。公式GitHub Releaseから取得し、添付された`SHA256SUMS.txt`とGitHub Artifact Attestationでファイルを確認してください。

Microsoft Store版は、同じソースから作成したStore用パッケージをMicrosoftの認定後にMicrosoftの署名で配布します。Storeの審査・公開状況はMicrosoft Store側の表示を優先してください。
