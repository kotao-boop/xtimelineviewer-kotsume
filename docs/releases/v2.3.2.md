# XTimelineViewer Kotsume Edition v2.3.2

> [!WARNING]
> GitHubで配布するEXE・ZIPはコード署名されていません。Windowsで「不明な発行元」または
> Microsoft Defender SmartScreenの警告が表示される場合があります。Microsoft Store版は、
> Storeの認定後にMicrosoftが署名して配布します。

## v2.3.1からの変更

- Xのログイン画面で「Googleで続ける」を選んだとき、認証画面が外部ブラウザーへ移り、
  ログイン結果がアプリへ戻らない問題を修正しました。
- 「Appleで続ける」も同じアプリ内認証ウィンドウで処理します。
- 認証ウィンドウは元のXログイン画面と同じWebView2プロファイルを使用するため、
  Xへ戻るためのCookieと`web_message`を共有できます。
- アドレスバーのない認証ウィンドウで不明なサイトを開かないよう、移動先をX、Google、
  Appleの正規HTTPSホストへ限定しました。
- Google・Apple認証時の通信をプライバシーポリシーへ追記しました。

本アプリがGoogle、Apple、Xのパスワードや認証コードを独自に読み取り、設定ファイルやログへ
保存する処理はありません。認証画面と認証情報はMicrosoft Edge WebView2内で各サービスが処理します。

## Xの現在のログイン仕様との照合

2026年8月28日にXの実際のログイン画面を確認し、Googleが`accounts.google.com/gsi/`、Appleが
`appleid.apple.com/auth/authorize`を利用することを確認しました。Appleは
`response_mode=web_message`を使用するため、認証用ウィンドウを外部ブラウザーへ切り離さず、
元画面との親子関係を維持する必要があります。

## 配布経路と署名

- Microsoft Store版：v2.3.1は認定審査中です。このGitHub緊急修正は、別途Store更新として扱います。
- GitHub版：未署名です。SHA-256とGitHub Artifact Attestationで配布ファイルを確認できますが、
  これらはコード署名や安全性の保証そのものではありません。

## 検証項目

- x64 / ARM64ビルド
- 224件の単体テスト
- Google・Apple・X以外の認証ポップアップを拒否するURL判定テスト
- UIスモークテスト
- CodeQL
- 依存関係レビュー
- SHA-256とGitHub Artifact Attestation

Google・Appleの実アカウントによる最終確認では、認証情報を開発者へ共有せず、利用者自身が
テスト用パッケージ上で入力します。
