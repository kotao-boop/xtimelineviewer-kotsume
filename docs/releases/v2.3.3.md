# XTimelineViewer Kotsume Edition v2.3.3

> [!WARNING]
> GitHubで配布するEXE・ZIPはコード署名されていません。Windowsで「不明な発行元」または
> Microsoft Defender SmartScreenの警告が表示される場合があります。

## v2.3.2からの変更

- XのGoogle・Apple認証で、最初の認証画面からさらに開かれる入れ子のポップアップにも、
  同じWebView2プロファイルを引き継ぐよう修正しました。
- 入れ子の認証画面が既定動作で外部Edgeへ出てしまい、認証結果を元のX画面へ返せなくなる
  問題へ対応しました。
- 認証中の外部URIスキーム起動を停止し、外部ブラウザーへ出たまま戻れない状態を防ぎます。
- 認証画面の要求先と失敗状態を、クエリ文字列や認証情報を除外して診断ログへ記録します。
- 自動整列、一時集中表示、一時非表示、一括復元を追加しました。

## 検証上の注意

GoogleとAppleは外部サービスであり、実アカウントによる最終確認は利用者本人が行います。
自動テストとビルドが成功しても、実ログインが成功するまでは「修正完了」と断定しません。
Google側がWebView2を埋め込みユーザーエージェントとして拒否した場合は、Xのユーザー名・
メールアドレス・電話番号とパスワードを使うログイン方法を案内する必要があります。

## 診断ログ

問題が続く場合は、`%LOCALAPPDATA%\XTimelineViewer\error.log`を確認します。ログには認証URLの
クエリ文字列を保存せず、scheme・host・pathとWebView2のエラー状態だけを記録します。
