# XTimelineViewer Kotsume Edition v2.8.6

同じ翻訳拡張機能が複数読み込まれることで、翻訳表示や通信が重複する問題を修正したGitHub版の改善リリースです。

## 主な変更

- 同梱版と利用者追加版で同じ名前の拡張機能がある場合、同梱版を優先して1つだけ読み込むようにしました。
- 重複している利用者追加版は削除せず、設定画面に未読み込みの理由を表示します。
- 同梱版をオフにした場合は、利用者追加版へ切り替えられます。
- 過去の起動でWebView2に残った同名の拡張機能登録を自動的に整理します。
- 拡張機能のオン／オフ切り替えを繰り返しても、ツールバーの設定ボタンが増えないようにしました。
- 日本語と英語の設定画面で、重複状態と切り替え方法を確認できます。

## 既存の利用者へ

同名の翻訳拡張機能を利用者追加フォルダーに置いている場合、初期状態ではアプリ同梱版が使われます。利用者追加版を使う場合は、「設定 → 拡張機能」で同梱版をオフにしてください。利用者追加版のファイルはアプリから削除しません。

GitHub版のEXE・ZIPはコード署名されていません。公式GitHub Releaseから取得し、添付された`SHA256SUMS.txt`とGitHub Artifact Attestationでファイルを確認してください。

## 翻訳について

翻訳機能は初期状態でオフです。翻訳を有効にした場合の通信は、設定画面で表示される同意内容とプライバシーポリシーに従います。Google側の公開エンドポイントの制限や仕様変更によって、翻訳が一時的に利用できない場合があります。

Microsoft Store版は別の提出・更新経路で管理されます。このリリースではStore提出物の作成・提出・公開は行いません。
