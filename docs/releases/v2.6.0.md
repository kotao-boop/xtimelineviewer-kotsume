# XTimelineViewer Kotsume Edition v2.6.0

## 配置を崩さず、必要な列へすばやく集中

v2.6.0は、複数のタイムラインを毎日使うときの「少し使いにくい」をまとめて改善する更新です。

- 2×2、2×3、上下2分割に収まらない数の列を開いた場合は、安全な自動配置へ切り替えて重なりを防止
- 集中表示を一時的な表示として扱い、終了時に直前の配置へ復元
- 一時非表示、集中表示、復元を同じ考え方で操作できるよう整理
- ワークスペースの操作ボタンを見つけやすくし、削除前に確認を表示
- 保存したワークスペースごとに、列と行の大きさを記憶

## サイズ変更と画面表示を改善

- 現在の配置で実際に動かせる境界線だけを表示
- グリッド配置では横方向と縦方向の両方をマウスで調整可能
- `Alt + Shift + 矢印キー`で、アクティブな列の境界を少しずつ調整可能
- 画面幅に応じて上部バーの文字や検索欄を自動的に整理
- 狭い列では使用頻度の低い操作を三点メニューへまとめ、本文を広く表示

## 設定画面と安全性を改善

- 設定、初回設定、プロファイル追加画面を高DPI表示に対応
- 設定画面の前回の大きさを記憶し、次回も同じ大きさで表示
- 「ボスが来た」モードの画面内表示を日本語・英語の言語設定に対応
- 境界線のドラッグ中にマウスが画面外へ出ても、最後のサイズを正しく保存

## 配布上の注意

GitHub版のEXE／ZIPはコード署名されていません。Windowsが「不明な発行元」またはSmartScreenの警告を表示する場合があります。公式GitHub Releaseから取得し、添付されたSHA-256チェックサムとGitHub Artifact Attestationでファイルを確認してください。Microsoft Store版はMicrosoftが署名する別の配布経路です。
