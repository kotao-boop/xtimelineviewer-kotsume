# XTimelineViewer Kotsume Edition v2.8.2

無料の翻訳方式を維持しながら、通信の集中を抑え、翻訳が表示されないときの状態を分かりやすくした更新です。

## 主な変更

- 同じアカウントのカラム間で翻訳通信を1件ずつ処理し、通信完了後も最低1.5秒の間隔を空けます。同じ本文への同時リクエストと成功結果を共有します。
- 自動翻訳は画面内に約0.4秒以上表示された投稿を対象にし、画面外で待機している投稿への新しい送信を抑えます。
- 通信制限（HTTP 429）時は即座の再送をやめ、30秒から段階的に待機時間を延ばします。翻訳先が指定する待機時間も尊重し、再起動後も待機状態を引き継ぎます。
- 翻訳先をXの表示言語ではなくアプリの表示言語（日本語・英語）に合わせます。
- 日本語と外国語が混ざった投稿や、日本語から英語への翻訳が誤って除外される問題を修正しました。
- 翻訳待ち・通信制限・失敗の状態を表示し、通常の失敗には手動の再試行ボタンを用意しました。

## 利用について

有償APIや別の翻訳サービスは追加していません。翻訳先の制限・仕様変更によって利用できない場合があります。この更新が既存の通信制限を直ちに解除するものではありません。

翻訳本文と結果はメモリー内で一時的に再利用し、ファイルやログへ永続保存しません。待機終了時刻と待機時間のみ、同意・設定と同じ拡張機能専用ストレージへ保存します。

## 配布上の注意

GitHub版のEXE・ZIPはコード署名されていません。初回起動時にWindowsの警告が表示される場合があります。公開物の`SHA256SUMS.txt`とGitHub Artifact Attestationでファイルを確認できます。

Microsoft Store版への提出・公開は、このGitHubリリースには含まれません。
