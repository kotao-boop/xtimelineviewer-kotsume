# Microsoft Store認証担当者向けノート v2.8.6

## アプリ概要

XTimelineViewer Kotsume Editionは、Microsoft Edge WebView2を利用してX（旧Twitter）のページを
複数列で表示する、オープンソースの非公式Windowsデスクトップアプリです。X Corp.、Twitter、
Google、Microsoftの提供・承認製品ではありません。

## 今回の更新

- 提出版: `2.8.6.0`
- 対象アーキテクチャ: `x64 / ARM64`
- 同じ翻訳拡張機能が複数回読み込まれ、翻訳表示や通信が重複する問題を修正しました。
- 同梱版と利用者追加版が同じ名前の場合は、同梱版を優先して1つだけ読み込みます。
- 重複する利用者追加版は削除せず、設定画面に未読み込みの理由を表示します。
- 同梱版をオフにすると、利用者追加版へ切り替えられます。
- 過去の起動でWebView2に残った同名拡張機能の登録を整理します。
- 拡張機能のオン・オフを繰り返しても、ツールバーの設定ボタンが重複しないようにしました。

## 基本確認手順

1. アプリを起動します。
2. Xアカウントでログインします。
3. 上部のワークスペースタブと列追加画面から、ホーム、通知、検索などを追加します。
4. 列の幅と高さ、集中表示、一時非表示、自動整列、新着件数を確認します。
5. 設定の拡張機能欄で、同梱拡張機能と利用者追加拡張機能のオン／オフを確認します。
6. 列ヘッダーの翻訳操作を行います。
7. Googleへ投稿本文を送信する説明が表示され、同意しない限り翻訳通信を開始しないことを確認します。
8. 列の詳細設定から同意を取り消し、再同意まで翻訳されないことを確認します。
9. 設定画面のバックアップから、ログイン情報を含めずに設定とワークスペースを保存できることを確認します。

## 通信と権限の理由

- `internetClient`: Xの表示、利用者が同意した翻訳、利用者操作によるメディア保存に使用します。
- `runFullTrust`: WinUI 3デスクトップアプリのウィンドウ、ローカルファイル、外部ブラウザー連携に使用します。
- WebView2拡張: Store版でも、利用者が設定画面から選んだ展開済みChromium拡張を読み込めます。
- Store版の更新: Microsoft Storeを使用します。GitHub版の更新確認とは別です。

`runFullTrust`を、サービスのインストール、XまたはEdgeの認証情報の取得、利用状況の収集には使用しません。

## プライバシー

- 公開プライバシーポリシー: `https://github.com/kotao-boop/xtimelineviewer-kotsume/blob/main/PRIVACY.md`
- 翻訳は初期状態でOFFです。
- 投稿本文は、利用者が説明に同意して翻訳を有効にした場合だけGoogleへ送信します。
- 翻訳方式は設定から無効化できます。無効中はGoogleへの翻訳通信を行いません。
- 同意状態はXのWebページから読めない拡張機能専用ストレージへ保存します。
- 利用者は列の詳細設定から同意を取り消せます。
- 開発者が運営する分析、広告、利用状況収集サーバーはありません。

## テスト用アカウント

Xの資格情報が必要な場合は、Partner Centerの認証担当者向け非公開欄だけで提供します。
パスワード、回復コード、多要素認証の秘密、本人確認情報をソースコードや公開文書へ保存しません。

## 既知の制限

- X側の画面構造や利用条件が変わると、一部の表示補助機能が一時的に動かなくなる可能性があります。
- Google／Appleの外部認証がアプリ内で完了できない場合は、X用パスワードによるログインを案内します。
- 翻訳には、利用者の同意後にGoogleの翻訳用エンドポイントへの通信が必要です。
- X上の利用者投稿には、アプリ開発者が管理していない内容が表示される可能性があります。
