# Microsoft Store認証担当者向けノート v2.3.1

## アプリ概要

XTimelineViewer Kotsume Editionは、Microsoft Edge WebView2を利用してXのタイムラインを複数列で
表示する、オープンソースの非公式Windowsデスクトップアプリです。X Corp.、Google、Microsoftの
提供・承認製品ではありません。

## 今回の更新

- 提出版: `2.3.1.0`
- 対象アーキテクチャ: `x64 / ARM64`
- Kotsume Edition専用のオリジナルアプリアイコンへ変更しました。
- Storeアイコンの白い縁を解消しました。
- アプリ内の旧アイコン制作者向け謝辞を、現在の事実関係に合わせて削除しました。
- アプリ機能、権限、通信先、保存データ形式に変更はありません。

## 基本確認手順

1. アプリを起動します。
2. Xアカウントでログインします。
3. ホーム、通知、検索などのペインを追加し、横並び表示を確認します。
4. 外国語の投稿で翻訳を有効にします。
5. Googleへ投稿本文を送信する説明が表示され、同意しない限り翻訳通信を開始しないことを確認します。
6. 設定の「同意設定」から同意を取り消し、再同意まで翻訳されないことを確認します。
7. 画像または動画の保存操作を行い、利用者が明示的に操作した場合だけ保存されることを確認します。

## 通信と権限の理由

- `internetClient`: Xの表示、明示的な翻訳、利用者操作によるメディア保存に使用します。
- `runFullTrust`: WinUI 3デスクトップアプリとしてのウィンドウ、ローカルファイル、外部ブラウザー連携に使用します。
- WebView2拡張: Store版ではアプリに同梱した翻訳拡張だけを読み込みます。利用者が追加したコードは読み込みません。
- Store版の更新: Microsoft Storeを使用します。GitHub版の自己更新機能とは別です。

`runFullTrust`を、サービスのインストール、Xの認証情報の取得、利用状況の収集には使用しません。

## プライバシー

- 公開プライバシーポリシー: `https://github.com/kotao-boop/xtimelineviewer-kotsume/blob/main/PRIVACY.md`
- 翻訳は初期状態でOFFです。
- 同意状態は、XのWebページから読めない拡張機能専用ストレージへ保存します。
- 利用者は同意を取り消せます。
- 開発者が運営する分析、広告、利用状況収集サーバーはありません。

## テスト用アカウント

Xの資格情報が必要な場合は、Partner Centerの認証担当者向け非公開欄だけで提供します。
パスワード、回復コード、多要素認証の秘密、本人確認情報をソースコードや公開文書へ保存しません。

## 既知の制限

- X側の画面構造や利用条件が変わると、一部の表示補助機能が一時的に動かなくなる可能性があります。
- 翻訳にはGoogleの翻訳用エンドポイントへの通信が必要です。翻訳を使わない場合はOFFのまま利用できます。
- X上の利用者投稿には、アプリ開発者が管理していない内容が表示される可能性があります。
