# Microsoft Store掲載更新案 v2.3.1

## 日本語

### このバージョンの新機能

Kotsume Edition専用のオリジナルアイコンへ刷新しました。Microsoft Storeの表示で生じていた
アイコン周囲の白い隙間を解消し、アプリ内の謝辞・作者情報も現在の事実関係に合わせて訂正しました。
機能や保存データの互換性に変更はありません。

### スクリーンショット

`docs/store/screenshots/ja-JP/01-multiple-timelines.png`

3つのタイムライン、翻訳表示、検索結果を同時に表示している実画面です。左上の個人アカウント名と
ハンドルは、画像生成を使わず利用者本人が手作業で削除しました。

## English

### What's new in this version

Introduced an original app icon created specifically for Kotsume Edition. This update also removes the white
fringe previously visible around the Store icon and corrects the in-app acknowledgements and authorship details.
There are no compatibility changes to features or saved data.

### Screenshot

Use `docs/store/screenshots/ja-JP/01-multiple-timelines.png` until a separate English UI screenshot is available.
The image shows three timelines, translated posts, and search results at the same time. The user's account name
and handle were manually removed without generative image editing.
